# ContextSnap 0.2.0-rc.1 — Preview

An optional prerelease preview of changes newer than the existing public v0.2.0.
The RC label does not replace or retag that stable release, which remains
the default download. Use this preview to try source navigation and editable image layers.

## Install the preview

Use Chrome 120 or later. No Node.js, npm, account, or server is needed.

1. Download [contextsnap-0.2.0-rc.1-chrome.zip](https://github.com/vitqst/vit-contextsnap/releases/download/v0.2.0-rc.1/contextsnap-0.2.0-rc.1-chrome.zip),
   not GitHub's automatically generated **Source code** archive.
2. Unzip it into a folder you will keep on your computer.
3. Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**.
4. Select the extracted folder containing `manifest.json`, then pin ContextSnap.

Copy or download open work before switching extension versions. If you install both
versions separately, enable only one while testing to avoid shortcut conflicts.
ContextSnap is not published in the Chrome Web Store; installation is manual.

The [SHA256SUMS](https://github.com/vitqst/vit-contextsnap/releases/download/v0.2.0-rc.1/SHA256SUMS)
asset contains the SHA-256 checksum for this preview ZIP. The existing
[stable v0.2.0 release](https://github.com/vitqst/vit-contextsnap/releases/tag/v0.2.0)
and its downloads remain separate.

## What to try

- **Back to website** keeps the editor and undo history open. Reuse the original capture
  tab if it still shows the captured URL; otherwise open the saved HTTP(S) URL. Recent
  exports reopen their saved URL. Local imports have no website button.
- **Add image**, paste, or drop a local PNG/JPEG/WebP into an open screenshot as a layer.
  Move it, resize proportionally using a corner, duplicate, delete, nudge, and undo/redo.
  Paste inside text fields is unchanged. **Open another image** still replaces the
  background; with an empty editor, paste/drop opens a background image.
- **Send backward / Bring forward** reorder images among images and drawings among
  drawings. Images stay below drawings and are included in blur, magnifiers, redaction,
  clipboard copies, and downloaded PNGs.

## Privacy and limits

There are no new permissions, dependencies, uploads, or services. Captures can contain
visible passwords and personal details; nothing is automatically redacted.
**Blur is not secure redaction. Use solid Redact and inspect your exported image.**
Redaction stays above image layers and lenses regardless of creation order.

Inserted images remain in memory, including assets needed for undo. Limits are 20 MB
per inserted file and 16 megapixels of inserted assets per session. Duplicates share
their asset; deleting a layer does not release its undo data. Start a new screenshot
to release that budget. SVG, remote image fetching, and editable-project persistence
are not supported. Animated PNG/WebP inputs become a single still frame.

Copy or download before closing/reloading: editable sessions are not saved. Recent
stores flattened exports and source metadata locally; full URLs may contain sensitive
query parameters or fragments. Back to website opens that saved URL only when requested.

## Versioning and verification notes

Chrome's numeric manifest version is `0.2.0.1`; its display name and package version
are `0.2.0-rc.1`. This allows the preview to order after the existing Chrome version
`0.2.0` without changing the stable release. A future stable package must use a higher
numeric version, such as `0.2.1` or `0.3.0`.

Native browser tests use an explicit 1920 × 1200 Xvfb screen and a five-second readiness
window before the actual capture shortcut. Only the known surface-unavailable protocol
error is retried; unrelated errors fail immediately. Whole tests are not retried, and
the assertions still inspect the real extension's exported PNGs.

Report ordinary bugs with synthetic examples through
[GitHub issues](https://github.com/vitqst/vit-contextsnap/issues). Use
[private security reporting](https://github.com/vitqst/vit-contextsnap/security/advisories/new)
for vulnerabilities; do not attach real secrets or private screenshots to public reports.
