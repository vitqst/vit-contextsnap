# ContextSnap 0.2.0-rc.2 — Preview

An optional prerelease with drawing refinements, plus the Back to website and image-layer
features introduced in rc.1. The existing [stable v0.2.0 release](https://github.com/vitqst/vit-contextsnap/releases/tag/v0.2.0)
remains the default download.

## Install or update the preview

Use Chrome/Chromium 120 or later. Chrome is tested; other Chromium browsers have not been
independently tested. No Node.js, npm, account, or server is needed.

1. Download [contextsnap-0.2.0-rc.2-chrome.zip](https://github.com/vitqst/vit-contextsnap/releases/download/v0.2.0-rc.2/contextsnap-0.2.0-rc.2-chrome.zip),
   not GitHub's automatically generated **Source code** archive.
2. Unzip it into a folder you will keep on your computer.
3. Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**.
4. Select the extracted folder containing `manifest.json`, then pin ContextSnap.

To update an existing unpacked installation, **copy or download open work first**.
Replace the files in its existing folder with the extracted rc.2 files, then click
**Reload** on the extension at `chrome://extensions`. Reopen the editor after updating;
editable sessions and undo history are not saved across reloads. If you instead load
the preview from a separate folder, enable only one ContextSnap version to avoid
shortcut conflicts.

ContextSnap is not published in the Chrome Web Store; installation and updates are manual.
The [SHA256SUMS](https://github.com/vitqst/vit-contextsnap/releases/download/v0.2.0-rc.2/SHA256SUMS)
asset contains the SHA-256 checksum for this preview ZIP.

## New in rc.2

- **Attached arrow labels** sit in a gap at the arrow's midpoint. Dragging a label moves
  its entire arrow. Labels wrap and keep their font size as the arrow length changes.
  Choose **Straight** or **Curved** for new or selected arrows; switching modes keeps the
  endpoints in place and preserves the bend for switching back.
- **Shadow** defaults on. Each arrow and its label share one toggle; sticky cards have
  a separate toggle. Other annotations and shape notes stay flat.
- **Notes on shapes:** double-click a shape to add or edit its note. Notes move with their
  shapes. Step notes sit below the numbered circle, or above near the bottom edge, so the
  number stays visible. Clearing a note keeps the shape.
- **Sticky notes — N:** click or drag to place a colored card, then type directly on it.
  Drag to move, resize from a corner, and double-click to edit again. Only sticky-card
  text scales when its object is resized; arrow labels and other text keep their size.
- **Responsive free draw:** supported pens use contact pressure; mouse or unavailable
  pressure falls back to speed measured over elapsed time. Faster mouse strokes get
  thinner. **Smoothing**, **Pressure influence**, and **Speed influence** sliders apply
  to the selected stroke and subsequent strokes. Set both influences to zero for
  constant width.
- **Extension preload warning fix:** remove generated JavaScript module preload hints
  that caused Chrome's cross-world resource mismatch and unused-preload warnings.
  Normal module imports and stylesheets remain bundled locally.

Drawing refinements support undo/redo, clipboard copy, and flattened PNG download.

## Also included from rc.1

- **Back to website** keeps the editor and undo history open. It reuses the original
  capture tab if that tab still shows the captured URL; otherwise it opens the saved
  HTTP(S) URL. Recent exports reopen their saved URL. Local imports have no website button.
- **Add image**, paste, or drop a local PNG/JPEG/WebP into an open screenshot as a layer.
  Move it, resize proportionally from a corner, duplicate, delete, nudge, and undo/redo.
  Paste inside text fields remains text editing. **Open another image** replaces the
  background and asks before discarding unexported work; with an empty editor, paste/drop
  opens a background image.
- **Send backward / Bring forward** reorder images among images and drawings among
  drawings. Images stay below drawings and are included in blur, magnifiers, redaction,
  clipboard copies, and downloaded PNGs.

## Privacy and limits

There are no new extension permissions, dependencies, uploads, or services. Captures can
contain visible passwords and personal details; nothing is automatically redacted.
**Blur is not secure redaction. Use solid Redact and inspect your exported image.**
Redaction stays above image layers and lenses regardless of creation order.

Inserted images remain in memory, including assets needed for undo. Limits are 20 MB
per inserted file and 16 megapixels of inserted assets per session. Duplicates share
their asset; deleting a layer does not release its undo data. Start a new screenshot
to release that budget. SVG, remote image fetching, and editable-project persistence
are not supported. Animated PNG/WebP inputs become a single still frame.

Copy or download before closing/reloading: editable sessions are not saved. Recent
stores flattened exports and source metadata locally; full URLs may contain sensitive
query parameters or fragments. Back to website opens that saved URL only when requested.

## Versioning and verification notes

Chrome's numeric manifest version is `0.2.0.2`; its display name and package version are
`0.2.0-rc.2`. This orders the preview after stable `0.2.0` and rc.1's `0.2.0.1`. A future
stable package must use a higher numeric version, such as `0.2.1` or `0.3.0`.

Automated coverage includes attached-label movement, fixed arrow-label font size, shadow
toggles, sticky editing/resizing, shape notes, pressure/speed-dependent stroke widths,
undo, clipboard PNG export, cropped redaction overlap, and native Chrome capture.
Pen pressure is exercised through Chrome's input protocol; physical stylus hardware
has not been manually verified. See [browser verification](https://github.com/vitqst/vit-contextsnap/blob/v0.2.0-rc.2/tests/README.md).

Report ordinary bugs with synthetic examples through
[GitHub issues](https://github.com/vitqst/vit-contextsnap/issues). Use
[private security reporting](https://github.com/vitqst/vit-contextsnap/security/advisories/new)
for vulnerabilities; do not attach real secrets or private screenshots to public reports.
