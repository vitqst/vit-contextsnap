# ContextSnap 0.2.0-rc.3 — Label placement fixes

This optional prerelease fixes annotation labels and includes the features from rc.1 and rc.2.
The [stable v0.2.0 release](https://github.com/vitqst/vit-contextsnap/releases/tag/v0.2.0) remains
available as the default download.

## What's changed

- **Arrow labels start at the tail**, above the starting endpoint. Drag a label independently
  of its arrow. Its saved offset follows the arrow when moved or resized. **Reset label position**
  returns it to the tail.
- **Rectangle labels start above the rectangle**, outside its top edge. Choose **Top**, **Bottom**,
  **Inside**, or **Free (draggable)** in the properties panel. Dragging a label automatically selects
  Free. Drag the outline to move the rectangle or use its corner handles to resize it.
- **Consistent labels:** arrow and shape labels share typography, adjustable font size, and their
  shape's color. Labels have no white box, white outline, connector line, or text shadow.
  Long labels wrap; font size stays fixed when shapes resize. Preview and flattened PNG export
  share the same layout and rendering.
- **Independent dragging** supports undo/redo and starts from the visible label position when
  constrained by the image or crop. Moving a label away from a filled shape does not make the
  empty space between them clickable.

Double-click a shape or its label to edit its text. Labels remain bounded by the screenshot or
crop; at an image edge the visible position may be constrained. Sticky-card text remains part
of its colored card and scales with that card.

## Install or update

1. Download [contextsnap-0.2.0-rc.3-chrome.zip](https://github.com/vitqst/vit-contextsnap/releases/download/v0.2.0-rc.3/contextsnap-0.2.0-rc.3-chrome.zip).
2. Extract the ZIP into a folder you will keep.
3. In Chrome, open `chrome://extensions`, enable **Developer mode**, and select **Load unpacked**.
4. Choose the extracted folder containing `manifest.json`.

To update an existing unpacked installation, export open work first, replace the files in its
folder with the rc.3 files, then click **Reload** at `chrome://extensions`. Reopen the editor.
Editable sessions and undo history do not survive reloading. If installing into a separate
folder, enable only one ContextSnap version to avoid shortcut conflicts.

Chrome/Chromium 120 or later is required. Chrome is tested; other Chromium browsers have not
been independently tested. Installation and updates are manual; no Chrome Web Store listing,
Node.js, account, or server is required.

The [SHA256SUMS](https://github.com/vitqst/vit-contextsnap/releases/download/v0.2.0-rc.3/SHA256SUMS)
asset verifies the release ZIP.

## Included features and limits

All [rc.2 drawing refinements](https://github.com/vitqst/vit-contextsnap/blob/v0.2.0-rc.3/docs/releases/0.2.0-rc.2.md)
and rc.1 image layers and Back to website navigation are included, with label behavior replaced
by the changes above. This release adds no permissions, dependencies, uploads, or services.

Export before closing or reloading: editable objects remain in the open session. Recent stores
flattened exports and source metadata locally. Use solid Redact for private details; blur is
not secure redaction. Inserted images are limited to 20 MB per file and 16 megapixels per session.

## Versioning and verification

Package/display version: `0.2.0-rc.3`. Chrome numeric version: `0.2.0.3`, which sorts after rc.2
and the existing stable build. A future stable package must use a higher numeric version.

Regression coverage checks label anchors, independent dragging, movement and resizing, presets,
undo, crop bounds, shared typography, and flattened PNG pixels over colored screenshots.
Repository checks cover TypeScript, lint, formatting, unit tests, and a production build;
Chrome tests cover editor workflows, clipboard export, packaging, navigation, and capture.
