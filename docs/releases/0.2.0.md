# ContextSnap 0.2.0

The first public release of ContextSnap: a local-first Chrome extension for turning
screenshots into clear visual feedback. Version 0.1.0 was an internal development version,
not a previous public release.

## Install in Chrome

Use Chrome 120 or later. No Node.js, npm, account, or server is needed for this download.

1. Download [contextsnap-0.2.0-chrome.zip](https://github.com/vitqst/vit-contextsnap/releases/download/v0.2.0/contextsnap-0.2.0-chrome.zip).
   Choose this extension ZIP, not GitHub's automatically generated **Source code** archive.
2. Unzip it into a folder you will keep on your computer.
3. Open `chrome://extensions` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
5. Pin ContextSnap, open an ordinary website, and choose **Select an area** or **Visible page**.

ContextSnap is not published in the Chrome Web Store. This release is installed manually
as an unpacked extension; other Chromium browsers have not been independently tested.
The [SHA256SUMS](https://github.com/vitqst/vit-contextsnap/releases/download/v0.2.0/SHA256SUMS)
asset provides the ZIP's SHA-256 checksum for download verification.

## Included

- Visible-page and selected-area capture, opening in a dedicated editor tab.
- Editable sketch or clean arrows with curved handles, wrapped labels, independent label
  sizing, and draggable label positions.
- Pen, rectangles, text, numbered steps, circular magnifiers, region blur, and solid redaction.
- Move, duplicate, delete, crop, zoom, and undo/redo; selection handles stay out of exports.
- Copy flattened PNGs to the clipboard or download them. Open, paste, or drop a local
  PNG, JPEG, or WebP as the screenshot to edit.
- Local Recent exports, with individual removal and Clear all.
- MIT-licensed source, bundled third-party notices, contributor guidance, and automated tests.

## Privacy and limits

Processing stays on your device, with no telemetry or automatic uploads. Captures can
contain passwords, personal details, and other visible content; nothing is automatically
redacted. **Blur is not secure redaction. Use solid Redact and inspect your exported image.**
Magnifiers use the blurred/redacted screenshot and cannot uncover masked source pixels.

An open editor retains its original image and undo history in memory. Copy or download
before closing or reloading: editable sessions are not saved. Recent stores flattened
exports plus the source title, full URL, and capture time locally; URLs may be sensitive.

Capture supports ordinary HTTP/HTTPS pages, not Chrome settings, the Chrome Web Store,
or file URLs. Full-page capture and live-page annotations are not included.

Report ordinary bugs through [GitHub issues](https://github.com/vitqst/vit-contextsnap/issues)
using synthetic examples. Report vulnerabilities privately via
[GitHub security reporting](https://github.com/vitqst/vit-contextsnap/security/advisories/new).
