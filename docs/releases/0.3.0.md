# ContextSnap 0.3.0

ContextSnap 0.3.0 adds a local Linux/macOS desktop editor alongside the Chrome extension,
and substantially improves annotation editing, rendering, and export quality.

## Highlights

- **Desktop screenshots:** capture outside the browser with native screenshot selection,
  clipboard PNG export, Save As, tray/menu-bar controls, and local image paste.
- **A smoother editor:** pan and zoom the complete workspace, resize crop and magnifier
  handles, reorder layers, and expand the output canvas around annotations.
- **Live annotation text:** text, labels, and notes render as you type with bundled Playpen
  Sans, including Vietnamese. Text can use a rounded color card; notes offer Auto sizing,
  manual presets, and a font-size slider.
- **More control:** bend arrows from their middle handle, select multiple objects with
  Shift-click or Ctrl/Cmd+A, and use Soft, Hard, or disabled shadows across annotations.
- **Safe effects and exports:** redactions remain opaque, blur and magnifiers respect layer
  order, and expanded PNGs preserve annotations outside the original screenshot.

## Install the Chrome extension

1. Download [contextsnap-0.3.0-chrome.zip](https://github.com/vitqst/vit-contextsnap/releases/download/v0.3.0/contextsnap-0.3.0-chrome.zip).
2. Extract it into a folder you will keep.
3. In Chrome, open `chrome://extensions`, enable **Developer mode**, then choose
   **Load unpacked** and select the extracted folder containing `manifest.json`.

Chrome 120 or later is required. ContextSnap remains locally processed and is not published
in the Chrome Web Store. The release `SHA256SUMS` asset verifies the downloaded ZIP.

For the Linux/macOS application, see the [desktop README](../../desktop/README.md).

## Privacy and limits

All capture and image processing stays on the device. Use **Redact** for sensitive content:
blur is not secure redaction. Editable sessions stay in memory, so copy or save work before
closing or reloading the editor.
