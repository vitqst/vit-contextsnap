# ContextSnap 0.3.1

ContextSnap 0.3.1 adds multi-screenshot composition to the desktop app and expands the
editor with precise lines and configurable arrow styles.

## Highlights

- **Add another screenshot:** the desktop app can capture a second screenshot into the
  current document as a selected image layer. Move, resize, reorder, annotate, duplicate,
  delete, undo, or redo it without replacing the original screenshot.
- **Safe capture flow:** canceling or failing an added capture preserves the current document
  and undo history. Conflicting edits stay locked only while capture is pending.
- **Line tool:** press **L** or select Line to draw a plain segment. Hold Shift while drawing
  or moving an endpoint to snap to horizontal, vertical, or 45-degree angles.
- **Configurable arrows:** choose one-way or two-way direction and the original open
  **Standard** style or a filled tapered **Bold** style. Both styles support straight and
  curved arrows, shadows, selection, undo/redo, labels, and flattened PNG export.

## Install the Chrome extension

1. Download [contextsnap-0.3.1-chrome.zip](https://github.com/vitqst/vit-contextsnap/releases/download/v0.3.1/contextsnap-0.3.1-chrome.zip).
2. Extract it into a folder you will keep.
3. In Chrome, open `chrome://extensions`, enable **Developer mode**, then choose
   **Load unpacked** and select the extracted folder containing `manifest.json`.

Chrome 120 or later is required. ContextSnap remains locally processed and is not published
in the Chrome Web Store.

## Install the desktop app

- **Linux (amd64):** download
  [contextsnap-0.3.1-linux-amd64.deb](https://github.com/vitqst/vit-contextsnap/releases/download/v0.3.1/contextsnap-0.3.1-linux-amd64.deb).
- **macOS (Apple silicon):** download
  [contextsnap-0.3.1-macos-arm64.dmg](https://github.com/vitqst/vit-contextsnap/releases/download/v0.3.1/contextsnap-0.3.1-macos-arm64.dmg).

The desktop packages are unsigned. Linux and macOS may show an installation or security
warning; on macOS, approve the app in **System Settings → Privacy & Security** if needed.
See the [desktop README](../../desktop/README.md) for prerequisites, source builds, and capture
behavior. Use the release `SHA256SUMS` asset to verify downloads.

## Privacy and limits

All capture and image processing stays on the device. Use **Redact** for sensitive content:
blur is not secure redaction. Editable sessions stay in memory, so copy or save work before
closing or reloading the editor.
